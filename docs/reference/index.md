# Package index

## Main Functions

Core methods for network-based transcriptomic analysis

- [`run_tkoi()`](https://baranzinilab.github.io/tkoi/reference/run_tkoi.md)
  : Run tKOI Analysis
- [`run_tkoi_app()`](https://baranzinilab.github.io/tkoi/reference/run_tkoi_app.md)
  : Launch the tKOI Shiny App
- [`get_analysis_graph()`](https://baranzinilab.github.io/tkoi/reference/get_analysis_graph.md)
  : Retrieve the Graph Used for a tKOI Analysis
- [`run_gene_enrichment()`](https://baranzinilab.github.io/tkoi/reference/run_gene_enrichment.md)
  : Run Gene Enrichment and Compare with TKOI Data
- [`get_neighboring_nodes()`](https://baranzinilab.github.io/tkoi/reference/get_neighboring_nodes.md)
  : Retrieve Neighboring Nodes in a Knowledge Graph
- [`make_gene_exploration_plot()`](https://baranzinilab.github.io/tkoi/reference/make_gene_exploration_plot.md)
  : Create Gene Exploration Plot
- [`export_gene_exploration_data()`](https://baranzinilab.github.io/tkoi/reference/export_gene_exploration_data.md)
  : Export Gene Exploration Data
- [`export_network_summary_statistics()`](https://baranzinilab.github.io/tkoi/reference/export_network_summary_statistics.md)
  : Export Network Summary Statistics to Excel
- [`visualize_topn()`](https://baranzinilab.github.io/tkoi/reference/visualize_topn.md)
  : Visualize Top Network Enrichment Statistics
- [`plot_network()`](https://baranzinilab.github.io/tkoi/reference/plot_network.md)
  : Plot a Local Network Around a Target Node from tKOI Results
- [`compute_network_enrichment()`](https://baranzinilab.github.io/tkoi/reference/compute_network_enrichment.md)
  : Compute Z-Score and P-Value for Node Pagerank

## Data and Annotations

Annotation datasets used for node interpretation

- [`tkoi_net`](https://baranzinilab.github.io/tkoi/reference/tkoi_net.md)
  : Human-Specific Heterogeneous Network
- [`anatomy_annotation`](https://baranzinilab.github.io/tkoi/reference/anatomy_annotation.md)
  : Anatomical Entity Annotations from UBERON
- [`celltype_annotation`](https://baranzinilab.github.io/tkoi/reference/celltype_annotation.md)
  : Cell Type Ontology Annotations (CL)
- [`clinicallab_annotation`](https://baranzinilab.github.io/tkoi/reference/clinicallab_annotation.md)
  : Clinical Laboratory Measurement Annotations (LOINC)
- [`complex_annotation`](https://baranzinilab.github.io/tkoi/reference/complex_annotation.md)
  : Protein and Molecular Complex Annotations
- [`compound_annotation`](https://baranzinilab.github.io/tkoi/reference/compound_annotation.md)
  : Chemical Compound Annotations
- [`disease_annotation`](https://baranzinilab.github.io/tkoi/reference/disease_annotation.md)
  : Disease Ontology (DO) Annotations
- [`ec_annotation`](https://baranzinilab.github.io/tkoi/reference/ec_annotation.md)
  : Enzyme Commission (EC) Number Annotations
- [`go_annotation`](https://baranzinilab.github.io/tkoi/reference/go_annotation.md)
  : Gene Ontology (GO) Term Annotations
- [`mirna_annotation`](https://baranzinilab.github.io/tkoi/reference/mirna_annotation.md)
  : Human miRNA Annotations (miRBase-style)
- [`pathway_annotation`](https://baranzinilab.github.io/tkoi/reference/pathway_annotation.md)

- [`protein_annotation`](https://baranzinilab.github.io/tkoi/reference/protein_annotation.md)

- [`proteindomain_annotation`](https://baranzinilab.github.io/tkoi/reference/proteindomain_annotation.md)

- [`proteinfamily_annotation`](https://baranzinilab.github.io/tkoi/reference/proteinfamily_annotation.md)
  : Protein Family Annotations (Pfam Clans)
- [`pwgroup_annotation`](https://baranzinilab.github.io/tkoi/reference/pwgroup_annotation.md)
  : Pathway Group Annotations (Reactome Interaction Sets)
- [`reaction_annotation`](https://baranzinilab.github.io/tkoi/reference/reaction_annotation.md)

- [`genes`](https://baranzinilab.github.io/tkoi/reference/genes.md) :
  Gene Metadata
- [`human_metabolites`](https://baranzinilab.github.io/tkoi/reference/human_metabolites.md)
